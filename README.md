NexaPC, an app that generates a configuration of a computer based on the components selected

# Application setup
To correctly setup the application make sure to:

1. add the .env to the root of project by following the pattern on .env.example (or else the app won't connect).
2. correctly setup the libs directory by going into : File -> Project Structure -> Dependencies -> Add -> Jar or Directories -> And select the whole libs directory.
3. running the code to make sure everything is good.

# Application Shortcuts & Keybindings

This guide outlines the essential keyboard shortcuts available to navigate and control the application efficiently.

## Navigation Mnemonics
To quickly switch between the main tabs or sections of the interface, use the **Alt** key combined with the numeric keys:

| Action | Shortcut |
| :--- | :--- |
| Focus Section 1 | `Alt` + `1` |
| Focus Section 2 | `Alt` + `2` |
| Focus Section 3 | `Alt` + `3` |
| Focus Section 4 | `Alt` + `4` |

## System Controls
Use these combinations for application-wide commands:

* **Quit Application**: `Ctrl` + `X`
    * *Immediately closes the application.*

## Search functionnality
We implemented 3 searches:
1. Motherboard search (All 3 criteria are mandatory).
2. Configuration search (All 3 criteria are mandatory).
3. Storage and cooling search (Only the motherboard field is mandatory, the other 2 are optionnal).
